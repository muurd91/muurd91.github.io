# muurd91.github.io

Служебный сайт: `/.well-known/assetlinks.json` подтверждает, что Android-приложение «Табель смены»
(TWA, https://muurd91.github.io/tabel-smeny/) принадлежит владельцу сайта — тогда оно открывается без адресной строки.
`.nojekyll` — чтобы GitHub Pages отдавал папку `.well-known` (Jekyll пропускает папки с точкой).
